PUBLICAR EN STREAMLIT

Los siete archivos del ZIP original están en original/ sin modificaciones.
streamlit_app.py añade una interfaz web e importa crypto_rsa.py directamente.
La interfaz de escritorio se sigue ejecutando con: python original/main.py

Para ejecutar la versión web:
  pip install -r requirements.txt
  streamlit run streamlit_app.py

Para publicar:
1. Subir esta carpeta completa a un repositorio de GitHub.
2. Abrir https://share.streamlit.io y seleccionar Create app.
3. Elegir el repositorio, la rama y streamlit_app.py como archivo principal.
4. Pulsar Deploy y comprobar que la aplicación permite acceso público.

El video y el ZIP original completo están también publicados sin modificaciones:
https://github.com/garzzaro/proyecto-rsa-grupo13/releases/tag/v1.0.0
La aplicación web carga el video desde esa versión si no está en original/.
